# Murphy Roszak — Portfolio

A standalone engineering and aviation portfolio built with HTML, CSS, and JavaScript. No dependencies, build step, account system, or backend.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory.

## Publish

Upload the contents of this directory to the root of your GitHub portfolio repository. Configure GitHub Pages to publish the repository root. All asset paths are relative, so the site works on a repository URL or a custom domain.

## Edit

- `index.html`: page sections and project previews.
- `styles.css`: colors, typography, layout, and responsive rules.
- `script.js`: project detail content and accessible dialog interactions.

## Content notes

Project illustrations and dashboard artwork are conceptual, not photographs or real financial data. The turbine kart is marked as in progress. This portfolio does not include private account information.

Before sharing with employers, review the project descriptions, add your preferred professional email and resume, and replace conceptual artwork with project photographs if desired.
